# 사단전 모드 (대한민국 시·군·구) 설계서

작성일: 2026-09-06 · 상태: 구현 (기존 육각 모드와 별도 화면 `region.html`, 저장 따로)

## 1. 요청 (사용자 말 그대로)

"우리나라 행정구역별로 상세하게 나누고, 특별시 광역시등 시는 구까지, 지방은 군까지 해버리고, 섬은 근처로 연결하고, 정해진 생산력이 있고, 생산력을 합쳐서 최대 500까지 해서, 방어인력 배치하거나, 사단 창설해서 할 수 있고, 사단인원은 무제한 인력증원할 수 있도록, 10,100,500, 최대까지 인력증원할 수 있게끔. 이미 있는 지역 내에는 반란 버튼으로 반란할 수 있고, 그러면 방어력과 사단인원을 이겨야 하고, AI가 나와 비슷하게 반란하고 생성하고 싸우는 식. 내가 막 죽어도 돼, 다시 하면 되니까."

## 2. 결정 (읽은 대로 + 세부는 위임)

| 항목 | 결정 |
|---|---|
| 지도 | 통계청 2013 시군구 251곳 → 일반시의 구는 시로 합쳐 **230개 지역**(구 69·시 78·군 83). 타일이 아니라 **지역 자체가 칸**(다각형), 인접은 경계 공유. 섬(제주·울릉·옹진·완도·진도·거제·남해, 청주/청원)은 경계가 가장 가까운 본토 지역과 **뱃길**로 연결 |
| 자원 | 골드 없음. 지역마다 **생산력**(인력/초: 구 0.5, 시 0.4, 군 0.25 × 특성·유산·난이도)이 있고 그 지역의 **인력 풀**에 쌓인다. 풀 한도 **500**(유산 '병참'으로 +10%/레벨) |
| 배치 | 풀에서 **방어인력**(그 지역에 고정, 수비) 또는 **사단**(움직이는 부대, 지역당 한 세력에 하나)으로 옮긴다. 버튼 +10 / +100 / +500 / 최대. 사단 인원은 상한 없음 |
| 이동·공격 | 내 지역의 사단을 선택 → 목적지 탭. 파병 비율 25/50/100%. 내 지역을 따라 행군(2초/지역, 유산 '행군'·축복으로 가속)하고, 남의 지역이면 가장 가까운 내 지역을 거쳐 진입해 전투 |
| 반란 | **남이 가진 지역**(중립 제외)을 선택하면 [반란 10/100/500/최대]. 인원은 내 모든 지역 풀에서(큰 쪽부터) 빠지고, 10초 뒤 **70%**가 그 지역 안에서 봉기해 방어인력+사단과 싸운다. 인접할 필요 없음. 지역당 세력마다 하나씩만 진행 |
| 전투 | 기존 규칙 그대로: 모든 편이 같은 속도로 깎이고 가장 센 편이 남는다(잔여 = 1등 − 2등), rate = 3 + 0.5·√전력합. 수비 전력 = (방어인력 + 사단) × 수비배율(특성: 산악 1.5·도시 1.2·해안 1.0·평야 0.9; 유산 '성벽술', 축복). 공격 전력 = 인원 × 공격배율. 손실은 방어인력·사단에 비례 배분. 점령하면 방어 0, 사단 = 잔여, 풀은 절반만 남는다(약탈) |
| 중립 | 처음엔 모든 지역이 중립. 방어인력 = (15 + 생산력×80) × (0.8~1.3 시드 난수) × (1 − 0.04×유산'개척') × 축복 |
| 세력 | 나 + AI 4 (환생 3회마다 +1, 최대 6). 내 수도 속초시(설악산), AI 수도는 그래프 거리로 서로 가장 먼 곳. 시작: 방어 30, 사단 50(+20×유산'초기 병력'), 풀 100(+100×유산'시작 골드') |
| AI | 8초 주기(유산·축복으로 지연). ① 국경 지역은 풀의 50%를 방어·50%를 사단, 내부 지역은 전부 사단으로 만들어 국경 쪽으로 이동 ② 사단×공격배율 > 상대 (방어+사단)×수비배율×1.3 이면 가장 약한 이웃 공격(80%), 주기당 3회 ③ 4주기마다 집결(이웃한 내 지역 셋의 사단을 모아 공격) ④ 6주기마다 반란: 풀 합 150 이상이면 (플레이어 우선) 가장 약한 남의 지역에 min(풀합×0.5, 300). AI 생산배율 = 난이도(0.6/0.8/1.0/1.2) + 환생 0.1 + 10분마다 0.1(최대 +1) |
| 끝 | 230개 전부 = 정복, 지역 0 + 사단·반란 없음 = 전멸. 둘 다 환생(포인트 = 기존 공식의 타일 수 자리에 지역 수, 난이도·유산 배수) → 상점 → 같은 모드로 새 판. "죽어도 다시 하면 된다" |
| 오프라인 | 같은 시뮬 1초 틱, 한도 8시간+유산 |
| 유산 매핑 | 풍요·징집 → 생산 +10%/레벨(둘 다), 무기 → 공격, 성벽술 → 수비, 초기 병력 → 시작 사단 +20, 시작 골드 → 시작 풀 +100, 개척 → 중립 −4%, 병참 → 풀 한도 +10%, 행군 → 속도, 약탈 → 점령 시 상대 풀을 절반 대신 (50+10×레벨)% 흡수, 통치·건축은 이 모드엔 없음, 오프라인·AI 둔화·유산 축복 그대로 |

## 3. 화면 (`region.html`)

- 지도: 230개 다각형을 주인 색(반투명)으로 채우고 경계선. 뱃길은 점선. 지역 가운데에 이름(확대 시)·🛡방어·⚔사단, 풀은 아래 작은 막대. 행군 부대는 경로(무게중심 연결선) 위 원, 반란 대기는 목표 지역에 깜빡이는 ✊, 전투는 ⚔ 깜빡임.
- 탭: 내 지역 → 선택(패널에 배치 버튼). 선택 중 다른 지역 탭 → 사단 비율만큼 이동/공격. 남의 지역 탭(선택 없음) → 정보 + 반란 버튼. 빈 곳 → 해제. 팬·핀치·⌖ 동일.
- 상단: 풀 합계 · 지역 수/230 · 배속 · ≡. 메뉴: 도움말·유산 상점·난이도·색약·저장·초기화·**육각 모드로**.
